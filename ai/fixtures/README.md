# 재현용 데이터

`dataset-a.jsonl`, `dataset-b.jsonl`은 테스트와 로컬 반입 예제를 위한 가상 업무 메일입니다. 실제 회사, 사람, 고객이나 비밀 데이터는 포함하지 않습니다. 두 파일의 ID와 용어는 서로 다르게 구성하여 데이터셋 교체 뒤 이전 자료가 섞이는지 확인합니다.

각 데이터셋은 같은 `recipient_group`, `language`, `situation`을 가진 독립적인 메일 사례 3개를 포함합니다. 보고서와 별도 고객 메일도 포함하여 메일 구성 근거가 문서 종류와 메타데이터를 구분하는지 확인합니다. 문단의 순서는 JSON 문자열의 `\n\n`으로 보존합니다.

모델을 대체하는 고정 응답은 `tests/`에만 있습니다. 실제 CLI는 이 자료를 입력해도 API 키와 모델 호출이 필요하며, 가짜 생성·검토 성공 결과를 사용하지 않습니다. 자동 테스트는 파이프라인, 근거 범위, 버전 고정 및 오류 처리를 검증하고 실제 AI의 한국어 평가 정확도를 측정하지 않습니다.

`practice-demo.jsonl`은 사용자가 직접 풀어볼 연습 문제집을 만들기 위한 한국어 가상 메일 4건입니다. 초기 STEP 1·2의 자료 요청, 회의 취소, 고객 일정 변경, 첫 출근 안내 시나리오를 참고했습니다. 모든 문서는 제목과 본문에 연습용 가상자료임을 표시하며, 실제 회사 규정이나 실제 고객 자료를 뜻하지 않습니다. A/B 교체 검증용 자료와 별개로 가져와 문제집을 생성하거나 수동 반입한 뒤, 실제 모델의 검토를 거쳐 활성화해야 합니다.

`practice-demo-catalog.json`은 위 자료에 대응하는 수동 작성 문제집입니다. `catalog import`로 후보를 등록한 뒤 실제 AI의 `catalog review`를 통과해야 `catalog activate`할 수 있습니다. 검토 결과나 승인 상태를 미리 채운 파일이 아닙니다.
